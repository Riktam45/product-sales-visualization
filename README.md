# Product Sales & Data Visualization

This repository contains an exploratory data analysis and visualization project using Python. The project demonstrates how to use industry-standard libraries to transform raw data into actionable insights through various plotting techniques.

## Features
- **Time-Series Analysis:** Visualizing temperature variations over a 5-day period using `Matplotlib`.
- **Categorical Data Analysis:** Comparing purchase values across different product categories using `Seaborn`.
- **Data Manipulation:** Utilizing `Pandas` and `NumPy` for efficient data handling.

## Tech Stack
- **Python 3.x**
- **Jupyter Notebook**
- **Matplotlib** (Line plots, grids, and markers)
- **Seaborn** (Stylized bar charts and categorical plotting)
- **Pandas** (DataFrame management)

## Project Structure
- `Product_Sales_Visualization.ipynb`: The main notebook containing the source code and generated visualizations.

## Sample Visualizations
The notebook generates:
1. Line graphs for environmental tracking (Temperature).
2. Bar charts for commercial data (Product Sales).
